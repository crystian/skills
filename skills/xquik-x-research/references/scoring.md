# Signal Scoring

Use this rubric to rank records.

| Factor | Range | Signal |
|---|---:|---|
| Intent | 0-5 | Buying, evaluating, switching, asking, or requesting recommendations |
| Pain | 0-5 | Frustration, workaround, urgency, repeated issue, or missing capability |
| Fit | 0-5 | Matches the product, audience, persona, or use case |
| Recency | 0-3 | More recent and active threads rank higher |
| Engagement | 0-3 | Replies, reposts, likes, quotes, or discussion depth |

Total signal score = intent + pain + fit + recency + engagement.

Use the score for ranking only. Explain the evidence behind each high-scoring record.
