# xquik-x-research

Analyze Xquik exports, REST API responses, or MCP output to produce evidence-backed X audience and market research.

Xquik is an independent third-party service. Not affiliated with X Corp. "Twitter" and "X" are trademarks of X Corp.

## Use it for

- Launch research from X conversations
- Audience theme discovery
- Competitor and creator monitoring
- Content and campaign angle generation

## Install

```bash
npx skills add crystian/skills --skill xquik-x-research
```
